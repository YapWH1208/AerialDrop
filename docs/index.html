What’s new

Day/Night pairs in 1.1.9, with the activation, recovery, and import fixes from 1.1.8.

Version 1.1.9

Day/Night wallpaper pairs

On verified macOS 27 builds, choose separate Day and Night videos, then explicitly apply Automatic selection. You can also select a fixed Day or Night member. Both videos stay protected during pair changes and recovery.

Unrelated missing media no longer blocks activation or removal. AerialDrop checks the selected wallpaper’s files before applying it, and keeps ordinary wallpaper activation available during pending recovery.

Pair playback is still being verified: imported-video playback, natural solar transitions after quitting, and lock/unlock checks remain pending.

Read the 1.1.9 release notes

Version 1.1.8

Safer activation and recovery

Wallpaper activation now verifies the selection macOS applied and reports when it needs attention. Backup restore rechecks the active wallpaper, blocks changes that would remove it, and preserves concurrent catalogue updates.

Import previews stay aligned when you change videos, rotated-video cropping is corrected, and conversion progress stays monotonic. Keyboard range selection starts from the focused wallpaper card, and the installer handles checksums and arguments more reliably.

Before you install: the unsigned-app notice

AerialDrop is ad-hoc signed and not notarized by Apple. The install methods above clear the macOS download quarantine, which disables Apple’s malware check for this app; you are trusting the publisher instead of Apple. Only install from the official YapWH1208/AerialDrop repository, and audit the open-source code if you have concerns. The only way to get Apple’s own verification is Developer ID notarization, which needs a paid Apple Developer account.

What happens when you import

Seven steps, one pipeline. Press play to watch it run, or step through it manually.

Choose your video

Pick any MP4 or MOV (H.264 or HEVC), or drop it straight into the Import pane. You can tune the name, crop, quality, and output resolution before anything is written.

  • MP4 / MOV
  • H.264 / HEVC
  • Any orientation

Validate the source

The source is checked for readable media and correct timing. Sources under 80 seconds are fine, the composer repeats them.

  • ≥ 79.5 s loops
  • Starts at PTS 0

Compose an 80-second loop

A video-only composition is built. Short sources are repeated via passthrough export with the loop duration snapped to whole 30 fps frames, so every boundary is a sync sample.

  • 80 s duration
  • Whole-frame loops
  • Passthrough repeats

Encode HEVC Main10

The composition is decoded with AVAssetReader and re-encoded to Apple’s own shape: HEVC Main10, 30 fps, 10-bit full-range YUV, Rec.709, temporal sub-layers with a 15 fps base layer, and 1.9 s closed GOPs.

  • HEVC Main10
  • 30 fps
  • 10-bit · Rec.709
  • Base layer 15 fps
  • Closed GOP 1.9 s

Generate the preview frame

A HEIF preview is captured at timestamp zero, the same way Apple’s catalogue entries carry their thumbnails, so your wallpaper shows up properly in System Settings.

  • HEIF @ t=0

Register in the catalogue

The video and preview are written into Tahoe’s private Aerial manifest as a full entry, after the current catalogue is automatically backed up to aerials/AerialDropBackups.

  • Backup first
  • Compare-before-write

Activate and refresh

When Set as wallpaper after importing is enabled, AerialDrop checks the installed files, links the wallpaper across all Spaces and displays, restarts macOS’s wallpaper services, and verifies the requested selection. If it cannot verify the change, the import summary offers a retry.

  • Linked selection
  • Restart + verify

Questions, answered

Does AerialDrop modify my original video?

No. Your source is opened read-only and never touched. A re-encoded copy is installed into the wallpaper catalogue.

Why does my video need re-encoding at all?

Tahoe’s native player expects HEVC Main10 with temporal sub-layers (a 15 fps base layer at 30 fps) and sync samples at loop boundaries. Without that shape, the unlock transition can fail with VideoSampleReadingErrors and leave a black desktop. AerialDrop encodes to exactly the shape Apple’s own aerials use.

My video is shorter than 80 seconds. Will it work?

Yes. Short sources are encoded once, then repeated via passthrough export. The loop duration is snapped to whole 30 fps frames so every loop boundary lands on a sync sample.

Is the app signed or notarized?

It is ad-hoc signed and not notarized. Gatekeeper may complain on first launch: right-click and choose Open once, or clear the quarantine. Only install from the official repository, and audit the open-source code if you have concerns.

Does AerialDrop need to keep running after setup?

No. Once a single wallpaper is imported and applied, macOS plays it natively. AerialDrop is only needed for importing and managing the catalogue. Day/Night Automatic selection is also intended to continue after quitting, but natural transitions for imported pairs remain unverified.

How do I set up a Day/Night wallpaper pair?

On a verified macOS 27 build, expand Day/Night Wallpaper in Library and choose two different imported videos for Day and Night. Changing these choices saves a draft; it does not change your desktop. Choose Apply Day/Night Wallpaper to register the pair and request Automatic selection across all Spaces and displays.

To use a fixed Day or Night video, choose that video’s Set as Wallpaper action. Applying an ordinary imported wallpaper replaces the active pair. Apply Day/Night Wallpaper again to return to Automatic.

macOS 26 keeps the single-wallpaper workflow. Pair application requires verified macOS 27 and a recognized wallpaper extension build; the current supported extension build is 313.0.4.401. Unfamiliar builds disable pair application.

Does Automatic follow Light and Dark appearance?

No. Day/Night Automatic selection uses macOS’s native solar-position format, independently of Light/Dark appearance. Exact transition times are not established. Imported-pair playback, natural transitions after quitting, and lock/unlock behavior remain unverified. See the Day/Night runtime checks for the remaining validation.

What should I do if activation needs attention?

Retry activation in AerialDrop, or apply another imported wallpaper. For a Day/Night pair, retry Apply Day/Night Wallpaper. If a pair change cannot be verified, previous and new pair videos stay protected across relaunch until a native reload is verified; Remove Anyway cannot bypass that protection.

A missing file for an unrelated wallpaper does not block applying a valid selection. The selected wallpaper’s required files must still be available.

Can I restore a backup while an imported wallpaper is active?

Use Restore Latest Backup in Maintenance. AerialDrop shows the backup in a confirmation and rechecks the active selection before and during restore. It refuses a restore that would remove the active wallpaper, overwrite unrelated catalogue changes, or replace protected Day/Night media. If verification fails, the safety backup is retained for recovery.

Where are my wallpapers stored?

Inside ~/Library/Application Support/com.apple.wallpaper/aerials/, with backups under aerials/AerialDropBackups and Store/AerialDropBackups. Use Open Aerial Storage Folder from the Maintenance menu to get there.

What if a future macOS update changes the catalogue format?

The catalogue is a private API, so it could change. Every write is backed up first, and Restore Latest Backup checks the active wallpaper and unrelated catalogue data before restoring. Day/Night application is disabled on unfamiliar builds. A system update may require an AerialDrop update, reimporting, or reapplying your wallpapers.
