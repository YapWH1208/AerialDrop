Why AerialDrop

Native by design, not by emulation

Every import becomes a first-class entry in Apple’s own Aerial catalogue, so macOS treats your video exactly like the built-in ones.

Native catalogue integration

Imports become full Tahoe Aerial entries with HEIF previews, visible under AerialDrop in System Settings → Wallpaper.

Native-compatible encoding

Re-encodes to HEVC Main10, 30 fps, 10-bit Rec.709 with temporal sub-layers — matching the sample groups of Apple’s own aerials, so lock/unlock playback stays smooth.

Loop-safe passthrough repeats

Sources shorter than 80 seconds are repeated by passthrough export with the loop snapped to whole 30 fps frames, so every loop boundary lands on a sync sample.

Automatic backups

Every write to the catalogue manifest is backed up first. The last known-good catalogue state always survives at aerials/AerialDropBackups.

Inline preview & tuning

The Import pane shows your source with a live 16:9 crop mask. Crop, quality, and output resolution are tuned in place — the source file is never modified.

Controllable Library preview

Installed wallpapers loop in a native preview sheet with a visible Play/Pause control that respects Reduced Motion.

In-app activation

Imported Aerials are applied across all Spaces and displays by default. Library also offers a manual Set as Wallpaper action and an Active status.

Maintenance tools

Validate the catalogue, open the storage folder, restore the latest backup, or remove all imported wallpapers — all from one menu.

How it works

One import, seven steps

Explore the pipeline behind every wallpaper. Press play to watch it run, or step through manually.

Choose your video

Pick any MP4 or MOV (H.264 or HEVC) — or drop it straight into the Import pane. You can review and tune the name, crop, quality, and output resolution before anything is written.

  • MP4 / MOV
  • H.264 / HEVC
  • Any orientation

Validate the source

The source is checked for readable media, correct timing, and loop-ability. Sources under 80 seconds are fine — they are repeated by the composer.

  • ≥ 79.5 s loops
  • Starts at PTS 0

Compose an 80-second loop

A video-only composition is built. Short sources are repeated via passthrough export, with the loop duration snapped to whole 30 fps frames so every boundary is a sync sample.

  • 80 s duration
  • Whole-frame loops
  • Passthrough repeats

Encode HEVC Main10

The composition is decoded with AVAssetReader and re-encoded to match Apple’s own aerials: HEVC Main10, 30 fps, 10-bit full-range YUV, Rec.709, temporal sub-layers with a 15 fps base layer, and 1.9 s closed GOPs.

  • HEVC Main10
  • 30 fps
  • 10-bit · Rec.709
  • Base layer 15 fps
  • Closed GOP 1.9 s

Generate the preview frame

A HEIF preview is generated at timestamp zero, the same way Apple’s catalogue entries carry their thumbnails — so your wallpaper shows up properly in System Settings.

  • HEIF @ t=0

Register in the catalogue

The video and preview are written into Tahoe’s private Aerial manifest as a full entry — after the current catalogue is automatically backed up to aerials/AerialDropBackups.

  • Backup first
  • Compare-before-write

Activate & refresh

The wallpaper is linked across all Spaces and displays, then WallpaperAgent and WallpaperAerialsExtension are restarted and the change is verified.

  • Linked selection
  • Restart + verify

Why native matters

  • No helper processes. Once imported, macOS plays your video with Apple’s own pipeline — nothing of AerialDrop needs to keep running.
  • Real transitions. The slow-down on unlock and the fade back to the desktop work exactly like Apple’s built-in aerials.
  • Power-friendly. Playback runs under the system’s native wallpaper agent, not a third-party player.

Install

Three minutes to a custom sky

Requires macOS Tahoe 26 or later. Source videos: MP4 or MOV, H.264 or HEVC.

Heads up — unsigned app. AerialDrop is ad-hoc signed and not notarized by Apple. Installation clears the macOS download quarantine (disabling Apple’s malware check for this app), so you are trusting the publisher instead of Apple. Only install from the official YapWH1208/AerialDrop repository, and audit the open-source code if you have concerns. The only way to get Apple’s own verification is Developer ID notarization (paid Apple Developer account).

One command, and the cask tracks new releases automatically — brew upgrade --cask aerialdrop keeps you current.

brew install --cask yapwh1208/tap/aerialdrop

To upgrade later:

brew update && brew upgrade --cask aerialdrop

Downloads the latest release, verifies its sha256 checksum against the release metadata, installs AerialDrop.app into /Applications, and clears the download quarantine.

curl -fsSL -o install.sh https://raw.githubusercontent.com/YapWH1208/AerialDrop/main/install.sh
bash install.sh

Useful options: install.sh 1.1.3 (pin a version), --open (launch after install), --force (replace without asking), --install-dir <path>.

Download AerialDrop-<version>-macOS.zip from the Releases page, unzip, and drag AerialDrop.app into your Applications folder.

It is ad-hoc signed, so if Gatekeeper complains the first time: right-click → Open once, or clear the quarantine with xattr -dr com.apple.quarantine /Applications/AerialDrop.app.

Go to Releases

Requires Swift 6.2+ with the macOS 26 SDK (Xcode). The binary lands at .build/release/AerialDrop.

git clone https://github.com/YapWH1208/AerialDrop.git
cd AerialDrop
swift build -c release
Scripts/build-app.sh   # builds a proper .app bundle
open -n dist/AerialDrop.app

Usage

From video to live wallpaper

AerialDrop handles the plumbing — you handle the footage.

  1. 1

    Set up Apple Aerials

    Open System Settings → Wallpaper and download at least one Apple Aerial. If the native catalogue isn’t ready, AerialDrop shows Open Wallpaper Settings and Check Again instead of an empty Library.

  2. 2

    Choose & configure

    Use Choose Video… or drop an MP4/MOV in the Import pane, then review name, crop, quality, and output resolution. The source file is never modified. Set as wallpaper after importing is on by default.

  3. 3

    Import

    Press the persistent Import Wallpaper action or Command-Return. Progress stays visible even when the form is scrolled; cancel is offered while it’s still safe. Once installation starts, AerialDrop finishes.

  4. 4

    Continue

    The completion summary tells you whether the wallpaper was activated everywhere or installed without changing the desktop. Choose View in Library or Import Another.

  5. 5

    Quit

    AerialDrop can be quit after setup — macOS handles playback natively. The Maintenance menu stays available for validating the catalogue, opening the storage folder, restoring a backup, or removing everything.

Safety & compatibility

Your catalogue, guarded

AerialDrop writes into a private Apple data format — so it writes defensively.

Backup before every write

Manifest writes back up first to aerials/AerialDropBackups; linked-selection writes use separate binary-plist backups under Store/AerialDropBackups and refuse concurrent changes.

Restore when you need it

Restore Latest Backup replaces the catalogue with the newest AerialDrop backup — and refuses if Apple’s catalogue changed since the backup, so it never clobbers a newer system state.

A private format, treated with respect

The Aerial catalogue and its processes are not a public API. A future macOS update may change the manifest schema and require an AerialDrop update — that’s why every change is reversible.

FAQ

Questions, answered

Does AerialDrop modify my original video file?

No. Your source is opened read-only and never touched. A re-encoded copy is installed into the wallpaper catalogue.

Why does my video need re-encoding at all?

Tahoe’s native player expects HEVC Main10 with temporal sub-layers (a 15 fps base layer at 30 fps) and sync samples at loop boundaries. Without that shape, the unlock transition can fail with VideoSampleReadingErrors and leave a black desktop. AerialDrop encodes to exactly the shape Apple’s own aerials use.

My video is shorter than 80 seconds — will it work?

Yes. Short sources are encoded once, then repeated via passthrough export. The loop duration is snapped to whole 30 fps frames so every loop boundary lands on a sync sample.

What if a future macOS update changes the catalogue format?

The catalogue is a private API, so it could change. Every write is backed up first, Restore Latest Backup can put the catalogue back, and a future update may require an AerialDrop update.

Is the app signed or notarized?

It is ad-hoc signed and not notarized. Gatekeeper may complain on first launch — right-click → Open once, or clear the quarantine. Only install from the official repository, and audit the open-source code if you have concerns.

Does AerialDrop need to keep running after setup?

No. Once a wallpaper is imported, macOS plays it natively. AerialDrop is only needed for importing and managing the catalogue.

Where are my wallpapers stored?

Inside ~/Library/Application Support/com.apple.wallpaper/aerials/, with backups under aerials/AerialDropBackups and Store/AerialDropBackups. Use Open Aerial Storage Folder from the Maintenance menu to get there.

Can I remove everything again?

Yes — Maintenance → Remove All AerialDrop Wallpapers clears the imported entries, and any removal is backed up first. You can also manage entries in System Settings → Wallpaper.
